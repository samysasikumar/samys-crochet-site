# 🧶 Samy's Crochet

A handmade business website for **Samy's Crochet** — a small business selling handcrafted crochet plushies and gifts, built and designed by Samy Sasikumar.

🌐 **Live site:** [samysasikumar.github.io/samys-crochet-site](https://samysasikumar.github.io/samys-crochet-site)

---

## About the Project

This is a fully custom multi-page website built from scratch using HTML and CSS, designed to showcase Samy's handmade crochet products, event appearances, and personal story. The site was created as part of a real-world entrepreneurship.

The design follows a **warm & creative** aesthetic — deep purple backgrounds, soft pink and violet gradients, Playfair Display serif typography, and glassy card effects.

---

## Pages

| Page | Description |
|------|-------------|
| `index.html` | Home page with hero section, booth display photo, and featured product cards |
| `story.html` | About the maker — personal story and photo |
| `events.html` | Event spotlight gallery (2023, 2024, 2025) |
| `accolades.html` | Certificates and recognition (NJHS, Certificate of Recognition, Certificate of Appreciation) |

## Built With

- **HTML5** — page structure and content
- **CSS3** — custom styling, animations, responsive layout, glassmorphism effects
- **Google Fonts** — Playfair Display, Nunito, DM Mono
- **GitHub Pages** — free static site hosting

## What I Learned

- Designing and building a multi-page website from scratch
- CSS layout techniques including Flexbox and CSS Grid
- Creating smooth animations and scroll-triggered reveal effects using the Intersection Observer API
- Deploying a live website with GitHub Pages
- Connecting design and code to support a real small business
